# Personal Portfolio (HTML & CSS)

A clean and responsive one-page personal profile website built with **pure HTML and CSS**.

## Live Demo

- **Open project:** [GitHub Pages](https://puhavik.github.io/HTML_CSS_Project_1/)

## About the Project

This is an educational frontend project focused on practicing core web layout and styling skills without frameworks or JavaScript.

The page includes:
- Personal intro section with photo
- Social media links
- Hobbies block
- Work experience table
- Contact form layout

## Tech Stack

- **HTML5**
- **CSS3**
- **Google Fonts** (Roboto)

## Project Structure

```text
HTML_CSS_Project_1/
├── index.html      # Main page markup
├── style.css       # Styles and responsive rules
├── imgs/
│   └── me.jpeg     # Profile image
└── README.md
```

## Responsive Behavior

The layout adapts for smaller screens using media queries:
- Profile section switches from horizontal to vertical alignment
- Form fields stack for mobile readability

## Getting Started

### Option 1: Open Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/puhavik/HTML_CSS_Project_1.git
   ```
2. Enter the project directory:
   ```bash
   cd HTML_CSS_Project_1
   ```
3. Open `index.html` in your browser.

### Option 2: Use Live Demo

Open the GitHub Pages link above.
